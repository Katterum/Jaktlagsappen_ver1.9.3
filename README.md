Jaktlaget 1.9.3, hundförarvägar och passförslag.

- Rita jaktområde stegvis.
- Rita en eller flera hundförarvägar med start, mellanpunkter och slut.
- Varje väg visas i egen färg med märkta start- och slutpunkter.
- Ångra senaste punkt eller återöppna senaste väg.
- Passförslag väger in avstånd till hundförarvägar, jaktområde och observationer.
- Föreslagna pass kan läggas till eller tas bort manuellt.
- Vind visas för samtliga valda pass när togglingen är aktiv.
- Unik passning utan återanvändning.
